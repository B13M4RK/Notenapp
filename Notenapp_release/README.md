# Notenrechner

Ein moderner und übersichtlicher Notenrechner für die Schule, entwickelt mit Python und PyQt5. Mit dieser App kannst du deine Fächer verwalten, Noten eintragen und deinen aktuellen Notendurchschnitt automatisch berechnen lassen.

## Funktionen
* Verwaltung von Fächern und Kategorien (Schriftlich, Mündlich etc.)
* Berechnung des aktuellen Notendurchschnitts
* Saubere, übersichtliche Benutzeroberfläche auf Basis von PyQt5
